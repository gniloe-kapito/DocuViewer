# DocuViewer

**Открывайте документы прямо в браузере — без установки программ и загрузки файлов на сервер.**

[Открыть DocuViewer](https://gniloe-kapito.github.io/DocuViewer/) · [Исходный код](https://github.com/gniloe-kapito/DocuViewer)


DocuViewer поддерживает документы, таблицы, презентации, текстовые файлы и изображения. Файлы обрабатываются локально в браузере, поэтому для обычного просмотра не нужен аккаунт или серверная часть.

## Что умеет DocuViewer

- Открывает файлы через выбор на компьютере, перетаскивание, буфер обмена или ссылку.
- Позволяет держать несколько документов открытыми во вкладках.
- Ищет текст и подсвечивает найденные совпадения.
- Показывает миниатюры страниц и слайдов, когда формат это поддерживает.
- Даёт менять масштаб, поворачивать PDF и изображения, включать ночной и полноэкранный режимы.
- Поддерживает печать и экспорт в PDF.
- Позволяет сравнить два документа рядом и синхронизировать прокрутку.
- Сохраняет историю недавно открытых файлов. В историю попадают только метаданные, не сами документы.

## Поддерживаемые форматы

| Формат | Что можно посмотреть |
|---|---|
| **PDF** | Страницы, поиск, миниатюры и оглавление |
| **DOCX** | Текст, таблицы, стили и изображения |
| **XLSX, XLS, CSV** | Таблицы, листы и содержимое ячеек |
| **PPTX** | Слайды и их миниатюры |
| **TXT** | Текст, номера строк и поиск |
| **Markdown** | Исходный текст или форматированный просмотр, подсветка кода |
| **JSON, JSONL** | Форматирование, подсветка и сворачивание блоков |
| **RTF** | Текст с базовым форматированием |
| **Изображения** | JPG, PNG, GIF, WebP, SVG, BMP, ICO и AVIF |

Старые бинарные форматы `.doc` и `.ppt` не поддерживаются. Перед просмотром сохраните такие файлы в `.docx` или `.pptx`.

## Обмен файлами

Документ можно отправить другому человеку с помощью ссылки. Перед загрузкой DocuViewer показывает предупреждение и просит подтвердить отправку.

Файл шифруется прямо в браузере с помощью Web Crypto API (AES-GCM, 256 бит), после чего зашифрованная копия загружается на [kappa.lol](https://kappa.lol). Имя и тип файла также находятся внутри зашифрованных данных. Ключ расшифровки добавляется во фрагмент ссылки после `#` и не передаётся серверу при HTTP-запросе.

Учитывайте несколько особенностей:

- Максимальный размер загрузки — 100 МиБ.
- Сервис хранения не гарантирует срок доступности файла и может удалить его.
- Любой, у кого есть полная ссылка, сможет открыть документ.
- Ссылку можно скопировать повторно или отозвать из истории на устройстве, с которого её создали.
- QR-код создаётся локально в браузере.

## Приватность

При обычном просмотре файлы остаются в браузере и не отправляются на сервер DocuViewer. История хранит только имя файла, размер, дату и другие метаданные.

Для отображения PDF браузер отдельно загружает worker библиотеки pdf.js с CDN jsDelivr. Содержимое документа этому сервису не передаётся. При открытии файла по URL он загружается с указанного адреса.

Исключение — функция обмена ссылкой: в этом случае зашифрованная копия документа отправляется на kappa.lol после подтверждения пользователя.

## Запуск на своём компьютере

Нужен [Bun](https://bun.sh) версии 1.2 или новее.

```bash
bun install
bun run dev
```

Откройте `http://localhost:3000` в браузере.

Полезные команды:

```bash
bun run lint       # проверка ESLint
bun run typecheck  # проверка типов TypeScript
bun run build      # статическая сборка в папку out/
bun run preview    # просмотр собранной версии
```

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+O` | Открыть файл |
| `Ctrl+V` | Вставить файл из буфера обмена |
| `Ctrl+F` | Поиск по документу |
| `F3` / `Shift+F3` / `Enter` | Следующее или предыдущее совпадение |
| `Ctrl+P` | Печать |
| `F` | Полноэкранный режим |
| `N` | Ночной режим |
| `+` / `-` / `0` | Увеличить, уменьшить или сбросить масштаб |
| `←` / `→` / `Home` / `End` | Навигация по страницам |
| `Ctrl` + колесо мыши | Изменить масштаб |
| `Esc` | Выйти из полноэкранного режима или сравнения |

## Ограничения

- Большие файлы могут открываться медленнее и занимать много памяти браузера.
- В PPTX не воспроизводятся анимации и переходы; часть форматирования может отличаться от PowerPoint.
- Некоторые сложные элементы DOCX могут отображаться не так, как в Microsoft Word.
- Поиск по тексту внутри изображений недоступен.
